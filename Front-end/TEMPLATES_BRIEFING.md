## 📋 TEMPLATE 6: Requirements Prioritization (MoSCoW)

**Duration:** 1-2 hours  
**Format:** Workshop with stakeholders  
**Output:** Prioritized requirements list

### MUST HAVE (60% of scope)
```
These are non-negotiable. Project cannot launch without them.

1. [Requirement]
   Why: [Why is this critical?]

2. [Requirement]
   Why: [Why is this critical?]
```

### SHOULD HAVE (25% of scope)
```
These are important but project can launch without them.
Plan to implement in first update.

1. [Requirement]
   Why: [Why is this important?]

2. [Requirement]
   Why: [Why is this important?]
```

### COULD HAVE (10% of scope)
```
These are nice-to-have. Include only if time/budget allows.

1. [Requirement]
   Why: [Why would this be nice?]

2. [Requirement]
   Why: [Why would this be nice?]
```

### WON'T HAVE (5% of scope)
```
These are explicitly out of scope for this phase.
Can be reconsidered for future versions.

1. [Requirement]
   Why: [Why is this out of scope?]

2. [Requirement]
   Why: [Why is this out of scope?]
```

## 🎓 How to Use These Templates

### For Briefing Agent
1. Start with Template 1 (Initial Intake Questionnaire)
2. Follow up with Template 2 (Competitive Analysis)
3. Create personas using Template 3
4. Map user journeys with Template 4
5. Define goals using Template 5
6. Prioritize requirements with Template 6
7. Document constraints/risks with Template 7
8. Compile into brief using Template 8

### Timeline
- **Day 1 Morning:** Template 1 (interview)
- **Day 1 Afternoon:** Organize notes, Template 2 research
- **Day 2 Morning:** Complete research, draft personas
- **Day 2 Afternoon:** Stakeholder follow-up, finalize requirements
- **Day 3 Morning:** Compile all into brief
- **Day 3 Afternoon:** Get client sign-off

### Tips for Success
✅ Ask follow-up questions until you have clarity  
✅ Document everything during calls  
✅ Get examples and specific stories  
✅ Validate assumptions by asking "Is that right?"  
✅ Record calls (with permission) for team reference  
✅ Share rough version with team early  
✅ Get client sign-off on final brief
