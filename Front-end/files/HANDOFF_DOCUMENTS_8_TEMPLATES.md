# COMO USAR OS TEMPLATES

## Para cada handoff:

```
STEP 1: Copiar template (Fase relevante)
STEP 2: Preencher com informações específicas
STEP 3: Validar checklist
STEP 4: Enviar para próximo agente(s)
STEP 5: Agendar 45-min sync call
STEP 6: Próximo agente confirma entendimento
STEP 7: Seguir para próxima fase
```

## Formato de entrega:

**OPÇÃO A: Google Doc** (recomendado)
- Fácil colaborar
- Histórico de versões
- Acessível para todos

**OPÇÃO B: PDF**
- Mais formal
- Documentação

**OPÇÃO C: Email**
- Se documento é pequeno
- Menos ideal
