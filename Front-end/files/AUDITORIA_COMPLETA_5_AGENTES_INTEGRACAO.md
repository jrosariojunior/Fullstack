## 2.2 Problemas Identificados

### **Problema #1: Sobreposição de Responsabilidades**

```javascript
PROBLEMA: {
  agentes: ["SEO Master", "Content Optimizer", "Copywriter"],
  conflito: "Quem é responsável por quê?",
  
  exemplos: {
    exemplo_1: {
      pergunta: "Quem escreve o artigo final?",
      seo_diz: "Eu pesquiso keywords, forneço outline",
      contentopt_diz: "Eu escrevo o artigo otimizado",
      copywriter_diz: "Eu escrevo copy que converte",
      resultado: "CONFUSÃO - 3 agentes, 1 responsabilidade"
    },
    
    exemplo_2: {
      pergunta: "Quem otimiza para humanização?",
      contentopt_diz: "Eu reviso para humanização",
      copywriter_diz: "Eu escrevo humanizado",
      resultado: "SOBREPOSIÇÃO - ambos fazem a mesma coisa"
    }
  }
}

CAUSA_RAIZ: [
  "Falta de protocol claro de handoff",
  "Descrição de responsabilidades vaga",
  "Sem trigger point ('quando passa para próximo agente')",
  "Sem definição de 'done' para cada agente"
]
```
