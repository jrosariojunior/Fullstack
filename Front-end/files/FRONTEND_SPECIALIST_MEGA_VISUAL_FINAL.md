## 🎬 ANIMAÇÕES & TRANSIÇÕES EXTRAÍDAS

### VELOCIDADES PADRÃO

```
TRANSIÇÕES (UI Interations):

Fast (150ms):
├── Input focus ring
├── Hover states simples
├── Quick feedback
└── Ex: border-color change

Base (200ms) ← DEFAULT PARA UI:
├── Button hover/active
├── Card elevation change
├── Color transitions
├── Opacity fades
├── Ex: #3B82F6 hover change
└── Cubic-bezier: (0.4, 0, 0.2, 1)

Slow (300ms):
├── Card entrance
├── Modal animations
├── Dropdown open/close
├── Scale transforms
├── Ex: card scale 1 → 1.02

XSlow (500ms+):
├── Page transitions
├── Large layouts
├── Evitar em UI rápida
└── Máximo: 600ms
```

### EASING FUNCTIONS (Cubic Bezier)

```
EASE-IN-OUT (Recomendado):
├── cubic-bezier(0.4, 0, 0.2, 1)
├── Smooth, natural feeling
├── Use: 95% dos casos
└── Standard Tailwind: ease

EASE-OUT (Rápido inicio):
├── cubic-bezier(0.0, 0, 0.2, 1)
├── Fast start, slow end
├── Use: Hover states, quick feedback
└── Tailwind: ease-out

EASE-IN (Lento inicio):
├── cubic-bezier(0.4, 0, 1, 1)
├── Slow start, fast end
├── Use: Page transitions, important
└── Tailwind: ease-in

LINEAR (Sem aceleração):
├── Evitar em animações UI
├── Use: Apenas para timing
└── Artificial feeling
```
