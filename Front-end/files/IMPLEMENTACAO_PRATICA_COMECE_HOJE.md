# PASSO 1: CUSTOMIZE O PROJECT BRIEF (15 minutos)

## A. Abra o Template

```
Arquivo: PROJECT_BRIEF_COMPARTILHADO_TEMPLATE.md
Ação: Copie o conteúdo
Para: Google Doc (novo doc)
Nomeie: "[PROJETO] - Project Brief"
```

## B. Preencha Seções CRÍTICAS (não precisa preencher tudo):

### Seção 1: Project Information
```
Nome do Projeto: [Your Project Name]
Objetivo: [Clear, 1 sentence]
Target Audience: [Who? Demographics]
UVP (Unique Value Prop): [Why choose you vs competitors?]
```

**Exemplo:**
```
Nome: Sustainable Yoga Mats E-commerce
Objetivo: Build high-converting e-commerce platform for eco-friendly yoga mats
Target: Women 25-45, professional, high income, wellness-focused
UVP: "Most sustainable yoga mats, tested by 10k practitioners"
```

### Seção 2: Business Goals
```
Primary Goal: [Revenue / Traffic / Conversion?]
Goal #1: [Specific number + timeline]
Goal #2: [Specific number + timeline]
Goal #3: [Specific number + timeline]
Timeline: [Project duration - weeks]
```

**Exemplo:**
```
Primary Goal: Revenue ($50k first year)
Goal #1: 100k organic visitors/month (by month 6)
Goal #2: 3% conversion rate (average for e-commerce)
Goal #3: $500k revenue year 1
Timeline: 16 weeks
```

### Seção 3: Technical Requirements
```
Stack: [React/Vue/etc, Next.js/Nuxt, TypeScript, Tailwind, etc]
Lighthouse Target: 90+
Core Web Vitals: LCP < 2.5s, FID < 100ms, CLS < 0.1
Accessibility: WCAG AA
Testing: 80%+ coverage
```

**Exemplo:**
```
Stack: React 19, Next.js 16, TypeScript 5.9, Tailwind 4.2
Lighthouse: 90+
LCP: < 2.5s, FID: < 100ms, CLS: < 0.1
WCAG: AA (fully compliant)
Testing: 80%+ (Jest + RTL)
```

### Seção 5: SEO Requirements
```
Primary Keywords: [3-5 main keywords]
Target Volume: [search volume estimates]
Target Rankings: [Top 3, Top 5, Top 10?]
Content Strategy: [Pillar pages? Number of articles?]
```

**Exemplo:**
```
Primary: "best yoga mats", "sustainable yoga mats", "eco-friendly fitness"
Volume: 8000/month, 2500/month, 1200/month
Target: Top 5 for all three (12 weeks)
Content: 5 pillar pages + 40 cluster articles (total 45)
```

### Seção 7: Agentes & Responsabilidades
```
Agente #1 (Frontend): [What you'll build]
Agente #2 (Designer): [Design system + components]
Agente #3 (SEO): [Keyword research, strategy]
Agente #4 (Copywriter): [CTAs, emails, psychology]
Agente #5 (Content): [Articles, 1500+ words, humanized]
```

**Exemplo:**
```
Frontend: Homepage, product pages, blog, checkout → React components + Next.js
Designer: Design system (50 components), colors, typography, specs
SEO: 1000 keywords analyzed, competitor study, content clusters
Copywriter: CTAs optimized for psychology, 8 email sequences
Content: 35 articles (5 pillars + 30 clusters), 90+ humanized
```

### Seção 8: Timeline

```
Phase 1 (Planning): Week 1
Phase 2 (Research): Week 2-3 (SEO Master)
Phase 3 (Design): Week 4-5 (Designer)
Phase 4 (Content): Week 6-8 (Content + SEO)
Phase 5 (Copy): Week 9-10 (Copywriter)
Phase 6 (Frontend): Week 11-13 (Frontend)
Phase 7 (QA): Week 14
Phase 8 (Launch): Week 15+
```

**SAVE and SHARE:** 
```
File > Share
Add 5 agentes (emails)
Permission: Edit
Notify: Yes
Send!
```

# PASSO 7: RUN KICKOFF MEETING (Monday/Tuesday Next Week)

## Before Meeting (5 min before)

```
✓ Join Zoom 5 minutes early
✓ Test audio/video
✓ Have slides ready (if using)
✓ Have documents open (for reference)
✓ Notes app ready (to capture questions)
```

## During Meeting

```
USE AGENDA from email:

0:00-0:10 (10 min): Welcome
- "Thanks for joining! Excited to work with you!"
- 30-second project overview
- "Today: alignment on roles, timeline, how we work"

0:10-0:30 (20 min): Roles
- "Each of you has a specific role, no overlap"
- Go through each agente's role
- Ask: "Do you understand your role?" (wait for yes)

0:30-0:50 (20 min): Timeline
- Show timeline visual
- "You work weeks [X-Y], then hand off to [name]"
- "Here are sync meetings scheduled"
- Ask: "Timeline makes sense?" (wait for yes)

0:50-1:20 (30 min): Q&A
- "What questions do you have?"
- Answer completely (no vague answers)
- Write down all questions for documentation

1:20-1:50 (30 min): Communication
- "Here's how we communicate: Slack, Google Docs, meetings"
- Review Communication Protocol
- "Response times: 30min urgent, 2-4h high, 24h normal"

1:50-2:00 (10 min): Recap
- "Let me recap what we discussed..."
- Ask each agente: "Do you understand your role?" (one by one)
- Ask each agente: "Ready to start Phase 1?" (one by one)
- Record confirmations

AFTER MEETING:
- Thank everyone
- Share meeting notes
- Schedule next meetings (Phase 2, 3, etc)
```
